# Growing Up Multilingual — What the Evidence Says

A single-page data story on the pros and cons of raising multilingual children, built from peer-reviewed studies, ISC Research and the 2024 Eurobarometer.

- `index.html` — the page (charts drawn with D3, loaded from a CDN)
- `data/research.csv`, `data/context.csv` — every figure on the page, with citation and link per row

To view locally, open `index.html` in a browser. Published with GitHub Pages.
